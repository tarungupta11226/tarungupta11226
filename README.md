# Tarun Gupta portfolio redesign

This is a standalone redesign inspired by the public visual structure and typography of Sophia Tang's site:
https://sophtang.github.io/

The reference site uses Instrument Serif, DM Sans, and JetBrains Mono, with an academic one-page layout, profile block, updates, selected work, and expandable content.

The user's existing portfolio content was used as the content source. The design uses:
- background `#1c2e4a`
- light grey body text
- yellow accent
- responsive navigation
- scroll progress
- expandable experience and education items

The requested Git clone could not be performed in this environment because outbound Git access was unavailable, so the redesign was implemented as a clean standalone site rather than modifying the remote repository directly.
